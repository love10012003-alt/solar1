
# solar.lal.vn - Điện Mặt Trời Cần Thơ

Template Next.js miễn phí, fork từ startup-nextjs (MIT), viết lại tiếng Việt cho solar.lal.vn

## Deploy lên Vercel (1 phút)
1. Tạo repo mới trên GitHub: solar-lal-vn
2. Upload toàn bộ file trong folder này
3. Vào vercel.com -> Add New Project -> Import Git repo
4. Bấm Deploy, xong trỏ domain solar.lal.vn về

## Chạy local
```
npm install
npm run dev
```

## Cấu trúc edit
- `app/page.tsx`: Toàn bộ landing page
- `app/layout.tsx`: SEO, title
- `app/globals.css`: Tailwind + style
- Sửa SĐT, địa chỉ trong `page.tsx` (search HOTLINE)
